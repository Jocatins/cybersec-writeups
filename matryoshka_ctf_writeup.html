The Matryoshka Files – CTF Forensics Write‑up

Recovered Flag: mSJx5tmSzHP3

The Thought Process

The challenge title referenced Russian Matryoshka dolls, suggesting nested content hidden inside other content. The hints mentioned file size mismatches and multiple file signatures, which pointed toward file carving and embedded data rather than image steganography.

Step 1 – Verify the file type

file challenge.jpg

This confirmed that the file was a normal JPEG image. Attackers often append hidden content to otherwise legitimate files.

Step 2 – Examine metadata

exiftool challenge.jpg

No suspicious metadata or comments were found, so attention shifted toward hidden binary content.

Step 3 – Search for embedded files

binwalk challenge.jpg

Binwalk detected a ZIP archive hidden at byte offset 1199138 containing flag.txt.

Step 4 – Carve the hidden archive

dd if=challenge.jpg of=embedded.zip bs=1 skip=1199138

The dd command copied everything after the ZIP signature into a standalone archive.

Step 5 – Validate and extract

file embedded.zip
unzip embedded.zip
cat flag.txt

The archive extracted successfully and revealed the final flag.

Why This Approach Worked

  • The challenge hints suggested hidden layers rather than visible clues.
  • JPEG files can legally contain appended data without breaking image rendering.
  • Binwalk excels at locating known file signatures embedded in other files.
  • Manual carving with dd is reliable when automatic extraction fails.

Real‑World Applications

  • Digital forensic investigations involving data exfiltration.
  • Malware analysis where payloads are hidden inside images or documents.
  • Detection of covert communication channels.
  • Incident response and insider threat investigations.
  • Validation of suspicious email attachments and downloaded files.

Key Lessons

  • Never trust file extensions alone.
  • Use multiple forensic tools because each reveals different artifacts.
  • When automatic extraction fails, manual carving techniques remain valuable.
  • Challenge names and hints often reveal the intended investigative direction.
