robots.txt Enumeration • Base64 Analysis • Flag Discovery

Challenge Overview

In this challenge, we were presented with a futuristic scenario in which robots had taken control of the world. Our objective was to infiltrate a robot control server and recover a secret key that could save humanity.

The challenge hints suggested that the server was hiding information in plain sight and specifically directed us toward examining the robots.txt file.

Reconnaissance

Inspecting the robots.txt file revealed several unusual paths:

User-agent: *
Disallow: /dHJlYXN1cmUudHh0
Disallow: /c2VjcmV0LnR4dA==
Disallow: /Y2F0Y2hfbWVfaWZfdV9jYW4vZmxhZy50eHQ=
Disallow: /YWRtaW4udHh0

At first glance, these paths appeared to be random strings rather than normal file names.

Analysis

Based on the challenge hints, the paths appeared to be encoded. Their format strongly resembled Base64.

CyberChef Steps

  1. Open CyberChef
  2. Paste each encoded string
  3. Apply "From Base64"
  4. Observe the output
Encoded Path Decoded Path
dHJlYXN1cmUudHh0 treasure.txt
c2VjcmV0LnR4dA== secret.txt
Y2F0Y2hfbWVfaWZfdV9jYW4vZmxhZy50eHQ= catch_me_if_u_can/flag.txt
YWRtaW4udHh0 admin.txt

Exploitation

After decoding the discovered paths, each file was manually investigated.

The most suspicious result was: 

catch_me_if_u_can/flag.txt

This matched the challenge hint referencing the movie Catch Me If You Can. 

https://challenge-site/catch_me_if_u_can/flag.txt

🚩 Flag Discovery

The challenge flag was exposed directly inside the file and required no additional decoding.

Vulnerability Identified

Information Disclosure via robots.txt

The application exposed sensitive resources through its robots.txt file.

Important: robots.txt is not an access control mechanism. It only provides instructions to search engine crawlers.

Developers attempted to hide paths using Base64 encoding. However, Base64 is simply an encoding format and provides no security.

Tools Used

  • Web Browser
  • CyberChef
  • Base64 Decoding Techniques
  • Manual Directory Enumeration

Key Takeaways

  1. Always inspect robots.txt during reconnaissance.
  2. Base64 is not a security mechanism.
  3. Hidden directories often contain valuable clues.
  4. Follow challenge hints carefully.
  5. Security through obscurity is ineffective.
  6. Enumeration frequently leads to flag discovery.

Lessons Learned

This challenge demonstrated how attackers can leverage publicly available information to discover hidden resources. It reinforced the importance of examining common reconnaissance targets such as robots.txt and recognizing common encodings like Base64 during investigations.
