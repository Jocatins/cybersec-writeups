01

Base64 Ninja Transmission

Objective — Analyze an intercepted message and recover the hidden secret buried under multiple encoding layers.

What is Base64?

Base64 is an encoding scheme that represents binary data as readable text. It is used extensively in email attachments, data transfer, web apps, and API communication.

⚠️
Base64 is NOT encryption Anyone who recognises the encoding format can instantly reverse it. It provides zero security on its own.

How to Recognise Base64

Characters
A–Z, a–z, 0–9
Plus + and /
Padding
Ends with = or ==
One or two padding chars
Example
SGVsbG8gV29ybGQ=
Decodes to: Hello World

The Challenge

An intercepted transmission looked like a standard Base64 string. The rookie analyst ran three decode passes, got an output that still resembled Base64, and assumed the job was done.

The challenge description contained the clue: "5 seals" — meaning the message had been encoded five times.

💡
Key Insight Always decode until the output no longer resembles Base64. Never assume a plausible-looking intermediate result is the final answer.

Methodology

1
Identify Encoding
Recognise the Base64 character pattern in the intercepted string.
2
Decode Repeatedly
Each pass peels one layer: Pass 1→4 still yields Base64. Pass 5 yields plaintext.
3
Verify Completion
Only stop when the result is no longer valid Base64.

Tools

CyberChef Recipe

# Stack 5 "From Base64" operations in CyberChef From Base64 From Base64 From Base64 From Base64 From Base64

Linux CLI

# Single decode base64 -d file.txt # Five-layer decode (pipe each pass) base64 -d file.txt | base64 -d | base64 -d | base64 -d | base64 -d

Key Lessons

🔓
Encoding ≠ Encryption
Base64 provides no confidentiality. Anyone can reverse it.
🎯
Trust Evidence, Not Assumptions
The rookie stopped too early. Always verify independently.
🔍
Follow Every Hint
"5 seals" directly indicated the number of decoding layers.
🧅
Multi-layer Encoding Exists
Attackers nest encodings to defeat casual inspection.

Leaky Login

Objective — Investigate a PCAP file and identify the credentials used in an unauthorized authentication event.

What is a PCAP?

A PCAP (Packet Capture) file contains recorded network traffic. Analysts use PCAPs to investigate incidents, recover credentials, detect attacks, reconstruct events, and analyse protocols.

Why FTP is Dangerous

🚨
FTP transmits credentials in plaintext Usernames, passwords, and commands are all visible to anyone capturing network traffic on the same path. The server in this challenge also explicitly rejected TLS: 534 Policy requires the use of a plain text session.

Reconstructed FTP Session

Using Follow TCP Stream in Wireshark on the FTP packets revealed the full authentication exchange:

220 vsFTPd 3.0.3 ── Attempt 1 ────────────────────── USER sysadmin PASS W3lcome1! 530 Login incorrect ── Attempt 2 ────────────────────── USER sysadmin PASS sysadmin123 530 Login incorrect ── Attempt 3 ────────────────────── USER sysadmin PASS 5vqfRp3y6W 230 Login successful
🔑
Critical Point The proof of compromise is not the password itself — it is the 230 Login successful response. A failed attempt proves nothing. A successful response proves authentication occurred.

Wireshark Display Filters

ftp dns http icmp ip.addr == 10.0.0.15 tcp.port == 21

CLI Extraction with tshark

# Show all FTP traffic tshark -r login.pcap -Y ftp # Find usernames tshark -r login.pcap -Y ftp | grep USER # Find passwords tshark -r login.pcap -Y ftp | grep PASS # Extract all printable strings (quick triage) strings login.pcap

Core Incident Response Lessons

01
Filter Before Investigating
Reduce noise first. Focus on the protocols that matter before diving into individual packets.
02
Reconstruct Conversations
Individual packets are fragments. TCP streams provide the full context.
03
Look for Authentication Events
A successful authentication response is often the clearest sign of compromise.
04
Know Legacy Protocol Weaknesses
FTP and Telnet expose credentials. SSH and HTTPS provide protection.
05
Separate Signal from Noise
Most captures are full of distractions. An analyst's job is to find what actually matters.
06
Evidence Must Be Verifiable
A password attempt is not proof. A successful authentication response is proof.
